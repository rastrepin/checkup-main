# Зв'язок обстежень планів з послугами клінік

Один файл на клініку: `<slug клініки>.json`. Ключ – `slug` обстеження з `content/plans/*.md`, значення – послуга з прайсу клініки.

Статуси:
- `mapped` – послуга знайдена: код, назва, ціна з прайсу;
- `included_in_consultation` – окремої послуги немає, ціна 0 (наприклад, вимірювання тиску на прийомі);
- `pending_decision` – потрібне рішення (наприклад, яка консультація);
- `not_in_source` – у прайсі, з якого взято ціни, такої послуги немає. Поки так, клініка не бере участі в сумі плану з цим рядком.

Ціни беруться лише з прайсу, який надала клініка або Ігор, з датою (`source.price_date`). Знижка на окремі позиції не застосовується (`discount_percent: 0`), ціна програми клініки замість суми послуг не підставляється.

Поки довідника обстежень (Р57) у базі немає, зв'язок живе тут. Коли з'явиться таблиця зв'язків у Supabase, ці файли переносяться туди.

Кредоклінік: файлу ще немає – чекаємо прайс окремих послуг з датою.
