# Оновлення цін клініки з таблиці цін

Джерело цін — Google Таблиця, де клініка вносить нові ціни з датою, з якої вони діють. Сайт читає ціни з бази (сторінки оновлюються з бази щогодини), тому досить оновити базу.

## Як це працює

1. Аркуш клініки з таблиці зберігається як CSV.
2. `sync-prices.mjs` зіставляє рядки з базою і друкує звіт: що оновиться, що чекає своєї дати, що потребує рішення.
3. Після перевірки звіту той самий запуск з `--apply` записує ціни в базу.

Що скрипт ніколи не застосовує сам (іде в «потребує рішення»):
- код, якого немає в базі;
- ціна не число, нуль, або без дати «діє з»;
- зміна більше ніж на 30% (поріг — `--max-change-pct`);
- дата старіша за чинну ціну.

## Ключі зіставлення

| Колонка «Ключ БД» | Що оновлюється |
|---|---|
| `program:<slug>` | `checkup_programs`: ціна зі знижкою = «Нова ціна», ціна без знижки = «Ціна без знижки» |
| `service:<код>` або порожньо | `clinic_services` за кодом клініки і містом (суфікс `-OH` у кодах ОН Клінік ігнорується) |

Назви колонок таблиці — у `columns.json`.

## Запуск

```
# перевірка (нічого не змінює)
node scripts/prices/sync-prices.mjs --clinic onclinic-kharkiv --city kharkiv --csv prices.csv

# запис у базу після перевірки
SUPABASE_URL=... SUPABASE_SERVICE_ROLE_KEY=... node scripts/prices/sync-prices.mjs --clinic onclinic-kharkiv --city kharkiv --csv prices.csv --apply
```

`--today YYYY-MM-DD` — дата, на яку застосовувати (за замовчуванням сьогодні за Києвом). `--db-json` — перевірка на знімку бази без мережі.
