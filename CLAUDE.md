# checkup-main

Основний домен check-up.in.ua: інформаційний навігатор і агрегатор пропозицій партнерів. Next.js 16 + Tailwind 4 + Supabase, Vercel.
Мова спілкування: українська.

## Гілки

- `main` — продакшн. НІКОЛИ не пушити в `main` напряму. Merge у `main` робить тільки Ігор.
- `dev` — робоча гілка.

## Як здавати роботу

За замовчуванням — Pull Request у `dev`, не прямий пуш.
Ігор не читає код, тому в описі PR завжди коротко людською мовою: що змінилося, у яких файлах, що перевірити на превʼю.

## Заборонено

- `git push origin main` з будь-якого приводу
- force push
- `vercel deploy` або `vercel --prod`

## Перед завершенням роботи

`npm ci` і `npm run build`. Якщо збірка падає — не відкривай PR, спочатку полагодь.

## Дизайн

Джерела, від старшого:
1. код;
2. `docs/components-map.md` у репозиторії `checkup-platform` — канон спільних компонентів;
3. журнали рішень дизайн-систем у Claude;
4. скіли `checkup-design` (візуал основного домену і спільне ядро) і `checkup-ux-platform`.

Правила:
- Загальні дизайн-скіли (frontend-design, theme-factory тощо) не використовувати — вони суперечать бренду v3 (italic-акцент у H1, eyebrow, капс однослівних кнопок, warm-фон).
- Кольори — лише через токени з `app/globals.css`. Нових hex-значень у `.tsx` не додавати.
- Crimson — лише фінальна відправка форми і бейдж знижки.
- Контраст тексту і CTA ≥ 4.5:1 на кожному фоні, де елемент з'являється.
- Шрифти — лише локально: файли з `public/fonts/` або `next/font` (він віддає шрифт зі свого домену). Не підключати `<link>` до fonts.googleapis.com.
